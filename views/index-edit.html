Fields

The path leads to a value in the stored data, e.g. address.city; for lists of structures, lines.title collects the titles of all lines. A referenced object is indexed as its UUID, and a path leads into it (a join): category.title indexes the title of the referenced category, tags.title those of all tags; when a referenced object changes, the documents built from it are updated by the next sync. Values are converted to the type; values that can't be converted are indexed as null. uuid and revision are always part of a document. Unique makes the value of the path unique among all objects of the class, like a UNIQUE constraint: a unique index is created (or dropped when unchecked), checked on every write, also outside this search index. Saving fails if stored objects share a value.
