    SELECT [DISTINCT] expressions [AS name] | * | alias.* FROM Class [alias]
            [[INNER] | LEFT] JOIN Class alias ON condition …
            [WHERE condition] [GROUP BY expressions] [HAVING condition]
            [ORDER BY expression [ASC|DESC], …] [LIMIT n] [OFFSET n]
    
        
    INSERT INTO Class (property, …) VALUES (value, …), … |
            UPDATE Class [alias] [SET property = value, …] [REMOVE path, …] [WHERE condition] (paths: tags[0], phones['fax'], tags[], friends.*.active) |
            DELETE FROM Class [alias] [WHERE condition] |
            ALTER CLASS Class DROP ATTRIBUTE property, … (ALTER TABLE … DROP COLUMN)
            — references with REF('uuid'); asks before writing, Dry run only lists the objects.
    
        
    Several statements separated by ; run one after another, until one fails.
            START TRANSACTION (or BEGIN) … COMMIT | ROLLBACK:
            all or nothing; a transaction left open at the end is rolled back. Every writing statement is atomic on its own.
            Preview runs everything and rolls it all back.
    
        
      
            
    • UUID is the UUID of an object: WHERE UUID = '…', p.UUID, p.category.UUID; a property named uuid is `uuid`.
      • 
            
    • Classes by their short name (Product) or full name in backticks (`App\Entity\Product`); without an alias, the short name is one.
      • 
            
    • Paths lead into referenced objects: p.category.title; the alias alone is the UUID of the object: JOIN Category c ON c = p.category.
      • 
            
    • Conditions: = != < <= > >=, IS [NOT] NULL, [NOT] IN (…), [NOT] BETWEEN a AND b, [NOT] LIKE 'Ho%' (ignoring case), [NOT] REGEXP '^Ho' (PCRE, anywhere, (?i) to ignore case), AND OR NOT; NULL is unknown, as in SQL.
      • 
            
    • Values: 'text' ('' for a quote), numbers, TRUE FALSE NULL; + - * /, || joins texts.
      • 
            
    • Functions: LOWER UPPER LENGTH TRIM SUBSTR ABS ROUND COALESCE IFNULL CONCAT CONCAT_WS REGEXP_SUBSTR REGEXP_REPLACE; math: CEIL FLOOR TRUNCATE MOD POW SQRT EXP LN LOG LOG10 LOG2 SIGN PI RAND SIN COS TAN ATAN2 DEGREES RADIANS CRC32 CONV, operators % DIV; metadata: CREATED(p) MODIFIED(p); aggregates: COUNT(*) COUNT([DISTINCT] x) SUM AVG MIN MAX.
      • 
            
    • ORDER BY, GROUP BY and HAVING take the names of the selection, ORDER BY and GROUP BY its positions (1, 2, …).
