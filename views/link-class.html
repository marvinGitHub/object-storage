Turns an attribute of every object of {{ classname }} that holds the UUID of a stored object as text, or a list of them, into a reference to that object, e.g. "friend": "3f2a…" becomes "friend": {"__reference": "3f2a…"}. Loading the objects then yields the referenced objects, and search indexes can follow the attribute (paths like friend.name). Other values and UUIDs without an object stay as they are; the attached search and unique indexes follow the changes. The attribute can be a path to a nested value: address.owner, contacts['alex'], friends[0], friends[*].partner.
