{# Syntax help of the Loupe engine, see https://github.com/loupe-php/loupe/blob/main/docs/searching.md #} Query: full-text search over the searchable fields, tolerating typos. "exact phrase" searches a phrase, -word excludes a word. Words of three or more letters also match as prefixes.
Filter (Loupe): = != > >= < <=, price BETWEEN 10 AND 20, tags IN ('a', 'b'), tags NOT IN ('a'), IS NULL, IS NOT NULL, IS EMPTY, IS NOT EMPTY, booleans as true/false, combined with AND, OR, NOT and parentheses. Strings in single quotes, ' doubled. Only filterable fields.
Patterns (added to Loupe): name CONTAINS 'om', name LIKE 'Ho%' (% any characters, _ one, \% a %), also with NOT, ignoring case; for filterable string fields (and lists) with at most 10,000 distinct values, e.g. names, not long texts: search those in the full text.
Sort: comma-separated field:asc / field:desc of sortable fields, _relevance:desc for the ranking.
Facets: comma-separated filterable fields, counts their values among the hits. {% set joined = fields|filter(f => '.' in f.path)|first %}
Joins: a field with a path into a referenced object holds its value, read when indexing, so it is filtered like any field: {% if joined %} {{ joined.name }}{{ joined.type starts with 'array' ? " IN ('…')" : (joined.type == 'number' ? ' > 10' : " = '…'") }}, or by its path {{ joined.path }}{{ joined.type starts with 'array' ? " IN ('…')" : (joined.type == 'number' ? ' > 10' : " = '…'") }}{% if not joined.filterable %} (needs to be filterable){% endif %}. {% else %} e.g. a field friendName with the path friend.name: friendName = 'Anna', or by its path friend.name = 'Anna'; through a list of references (labels.title) a list: labels IN ('red'). {% endif %} The reference itself is the UUID of the object: friend = '<uuid>' finds all objects referring to it. referencedUuids IN ('<uuid>') finds the documents built from an object, also several references away.
Paths: in filter, sort, facets and Search on, every field can be named by its path in dot notation, also nested further (friend.friend.name). There is no join at search time: a path needs a field of the index with this path; the builder offers to add one (the index is rebuilt).
