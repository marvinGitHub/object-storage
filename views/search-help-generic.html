{# Syntax help for engines without a help of their own #} Query: full-text search over the searchable fields.
Filter: a condition over the filterable fields, in the language of the engine {{ engine }}; see its documentation.
Sort: comma-separated field:asc / field:desc of sortable fields.
Facets: comma-separated filterable fields, counts their values among the hits.
Joins: a field with a path into a referenced object (e.g. friend.name) holds the value read when indexing, filtered like any field; the reserved attribute referencedUuids lists the objects a document was built from.
